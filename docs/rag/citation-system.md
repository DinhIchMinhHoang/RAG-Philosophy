# Citation System

## Overview

The system extracts and displays source citations for each answer generated by the LLM.

## Citation Extraction

### Step 4 Generator (rag_core/step4_generator.py)

```python
def ask(rag_chain, question: str) -> dict:
    result = rag_chain.invoke({"input": question})

    # Extract citations from context
    sources = []
    for doc in result.get("context", []):
        page = doc.metadata.get("page", "N/A")
        source = doc.metadata.get("source", "N/A")
        sources.append({"page": page, "source": source})

    return {
        "answer": result.get("answer", ""),
        "sources": sources,
    }
```

### Backend Service (backend/app/services/rag_service.py)

The streaming response appends sources to the final output:

```python
# Append sources footer
sources_footer = "\n\n---\n📚 **Nguồn tham khảo:**\n"
seen = set()
for doc in docs:
    source = doc.metadata.get("source", "N/A")
    page = doc.metadata.get("page", "N/A")
    key = f"{source}::{page}"
    if key not in seen:
        seen.add(key)
        sources_footer += f"- {source}, Trang {page}\n"
yield sources_footer
```

## Citation Format

### Display Format

```
📚 **Nguồn tham khảo:**
- filename.pdf, Trang 5
- another_doc.pdf, Trang 12
```

### Metadata Source

| Metadata | Value | Example |
|----------|-------|---------|
| `source` | Filename from PDF | "1706.03762v7.pdf" |
| `page` | 1-indexed page number | 5 |

## Citation in System Prompt

The system prompt instructs the LLM to cite sources:

```python
SYSTEM_PROMPT = (
    "Bạn là chuyên gia AI, trợ lý học tập cho sinh viên "
    "Đại học Công nghệ (UET). Bạn sẽ nhận được các đoạn trích dẫn "
    "từ giáo trình. Hãy trả lời câu hỏi dựa TRỰC TIẾP trên "
    "các đoạn văn được cung cấp dưới đây.\n\n"
    "Quy tắc:\n"
    "1. Chỉ sử dụng thông tin từ tài liệu được cung cấp.\n"
    "2. Nếu thông tin không đủ, hãy chỉ ra phần nào thiếu "
    "thay vì tự ý bổ sung.\n"
    "3. Luôn đính kèm số trang (VD: [Trang X]) vào cuối "
    "mỗi ý quan trọng trong câu trả lời.\n\n"
    "Tài liệu tham khảo:\n"
    "{context}"
)
```

Note: The page citation in the prompt is commented out (lines 32-33), but sources are still provided in the footer.

## Frontend Handling

The frontend receives SSE tokens and displays them in real-time. The sources footer appears at the end:

```javascript
// frontend/api.js
if (payload.token && onToken) {
    onToken(payload.token);  // Append to chat display
}
```

## Deduplication

The backend deduplicates sources using a set:

```python
seen = set()
for doc in docs:
    key = f"{source}::{page}"
    if key not in seen:
        seen.add(key)
        # Add to footer
```

This ensures unique citations even if multiple child chunks from the same page are retrieved.

## Limitations

1. **No inline citations**: Citations appear at the end, not inline with text
2. **No clickable links**: Source display is plain text
3. **No page ranges**: Only single page numbers (not "pages 5-7")

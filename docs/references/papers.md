# Papers

## RAG Fundamentals

1. **"Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks"** (Lewis et al., 2020)
   - Original RAG paper introducing the concept
   - arXiv: 2005.11401

2. **"Dense Passage Retrieval for Open-Domain Question Answering"** (Karpukhin et al., 2020)
   - Foundation of dense retrieval with BiEncoder
   - arXiv: 2004.09541

## Parent-Child Chunking

3. **"MultiVector Retriever with LangChain"** (LangChain Blog)
   - Explains parent document retrieval strategy
   - https://python.langchain.com/docs/modules/data_connection/retrievers/

## Evaluation

4. **"RAGAS: Automated Evaluation of Retrieval-Augmented Generation"** (Es et al., 2023)
   - Faithfulness, Answer Relevancy, Context Precision
   - https://github.com/explodinggradients/ragas

5. **"Measuring and Narrowing the Contamination Problem in Open-Domain LLMs"** (Sakota et al., 2023)
   - Hallucination detection methodology

## Advanced RAG

6. **"Corrective Retrieval Augmented Generation"** (Yan et al., 2024)
   - Uses retrieved docs to self-correct LLM outputs

7. **"GraphRAG: Enhancing RAG with Knowledge Graphs"** (Edge et al., 2024)
   - Microsoft's graph-based retrieval approach

## Related (In Project)

8. **"Attention Is All You Need"** (Vaswani et al., 2017)
   - Transformer architecture - 1706.03762v7.pdf in data/
